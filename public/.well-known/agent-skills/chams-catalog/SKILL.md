# Cham's Public Catalog

Use Cham's public catalog when an agent needs structured information about Cham's Small Meats & Preservatives products, wholesale enquiry details, or public discovery endpoints.

## Resources

- API catalog: `https://www.chams.com.au/.well-known/api-catalog`
- OpenAPI description: `https://www.chams.com.au/api/openapi.json`
- Products: `https://www.chams.com.au/api/products.json`
- API documentation: `https://www.chams.com.au/docs/api/`

## Authentication

The public catalog is read-only and does not require credentials.
