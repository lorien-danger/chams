# auth.md

Cham's Small Meats & Preservatives publishes a read-only public catalog for agents.

## Audience

Agents may use the public product catalog to answer questions about available products, formats, ingredients, storage guidance, and wholesale contact details.

## Authentication

The public catalog does not require OAuth credentials.

Protected API access is not currently offered. Agents that need wholesale account access, private pricing, or ordering workflows should contact Cham's directly.

## Discovery

- API catalog: `https://www.chams.com.au/.well-known/api-catalog`
- OAuth protected resource metadata: `https://www.chams.com.au/.well-known/oauth-protected-resource`
- Authorization server metadata: `https://www.chams.com.au/.well-known/oauth-authorization-server`
- Product catalog: `https://www.chams.com.au/api/products.json`

## Registration

Use `https://www.chams.com.au/contact/` for wholesale or integration enquiries.
